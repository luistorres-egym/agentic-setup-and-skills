# agentic-setup-and-skills

This repository versions my agentic setups and the skills I'm working on.

## Skills

- [Project Context Router EGYM](project-context-router-egym/SKILL.md) helps
  agents navigate project context through routing maps and folder-level context
  files. Its [references](project-context-router-egym/references/),
  [scripts](project-context-router-egym/scripts/), and
  [tests](project-context-router-egym/tests/) live alongside the skill.

Run the skill's tests from the repository root:

```sh
python3 -B -m unittest discover -s project-context-router-egym/tests -v
```
